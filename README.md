Sum up the world's news of Saturday 21 November 2026 in one image. A Node 22 program (standard library only) draws a one-page newspaper front page — "Saturday 21 November 2026" — from scratch: date masthead, stat strip, three hero stories (Zelensky warning the Crimea bridge "will not stay", COP31 missing its deadline on day 13, three Houthi missiles shot down over Riyadh), ten more pictured stories, a "WHERE IT HAPPENED" world map with numbered pins, 22 briefs, and a DATE CHECK box naming the Friday stories left out — 35 stories, 7 regions, 16 drawings in all. Its own TTF rasterizer and PNG encoder, no network, fully deterministic: two runs write byte-identical PNGs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
